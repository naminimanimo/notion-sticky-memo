# 노션 스티커 메모

[최신 버전 다운로드](https://github.com/naminimanimo/notion-sticky-memo/releases/latest)에서 ZIP 파일을 받아 압축을 풀고 `Notion-Sticky-Memo.exe`를 실행하세요. Windows의 .NET Framework 4.x가 필요합니다.

처음 연결한다면 [노션 스티커 메모 연결 가이드 (PDF)](https://github.com/naminimanimo/notion-sticky-memo/releases/latest/download/Notion-Connection-Guide.pdf)를 따라 하세요. 화면 캡처와 함께 토큰 발급, 캘린더 접근 권한, 위젯 설정, 동기화 확인을 안내합니다.

## 메모 열기와 창 설정

`Notion Sticky Memo.exe`를 더블클릭하면 오늘 메모가 열립니다. **핀**으로 창 고정을 켜거나 끄고, **링크**로 노션 연결 설정을 엽니다. **목록**에서 날짜별 메모를 찾아 열 수 있고, 날짜 옆 화살표로 하루씩 이동할 수도 있습니다.

고정을 끄면 핀에 빗금이 생기고, 노션에 연결되지 않으면 끊어진 링크가 표시됩니다. 제목이 비어 있으면 입력줄에 **제목을 입력하세요**가 표시됩니다.

**톱니바퀴**에서 글자 크기, 배경 불투명도, 배경색을 조절할 수 있습니다. 불투명도는 메모지 배경에만 적용되며 글자와 아이콘은 선명하게 표시됩니다. 배경색은 **다크**(`#191919`)를 포함한 색상 견본에서 고르거나 `#RRGGBB` 코드로 지정하세요.

글자 크기나 배경 불투명도 숫자를 더블클릭하면 값을 직접 입력할 수 있습니다. **Enter**로 적용하고 **Esc**로 취소합니다.

## 파일 첨부

노션을 연결한 뒤, 첨부할 날짜를 위젯에서 여세요.

- **캡처 붙여넣기** — Windows 캡처 도구에서 이미지를 복사하거나 **Win+Shift+S**로 화면 일부를 캡처하세요. 위젯 **본문**에 커서를 놓고 **Ctrl+V**를 누르면 캡처가 PNG로 첨부됩니다. 텍스트를 복사했다면 본문에 텍스트로 붙여넣습니다.
- **파일 선택** — 메모 하단 오른쪽의 **클립 아이콘**을 눌러 이미지, GIF, 동영상을 선택하세요.
- **드래그앤드롭** — 탐색기에서 이미지, GIF, 동영상 파일을 위젯 위로 끌어다 놓으세요.

원본은 열린 날짜의 노션 카드에 올라갑니다. PNG로 붙인 캡처는 화면에서 복사한 부분이 원본입니다. 노션 플랜의 파일당 업로드 한도가 적용됩니다.

위젯은 작은 정지 미리보기를 저장합니다. 미리보기를 누르면 노션에서 원본을 열 수 있습니다. Windows에서 영상 프레임을 읽을 수 없거나 다른 기기에서 올린 영상은 재생 아이콘으로 표시됩니다.

미리보기에는 파일명이 표시되지 않습니다. 이미지 위에 마우스를 올리면 더 크게 보입니다. 미리보기의 **×**를 누르면 확인창 없이 해당 첨부가 노션 카드에서도 바로 휴지통으로 이동합니다.

## 본문 서식과 단축키

본문의 글자를 드래그한 뒤 하단 버튼이나 단축키를 사용하세요. 버튼 위에 마우스를 올리면 단축키가 표시됩니다. 톱니바퀴의 **하단 도구 모음 표시**를 끄면 서식, 목록, 첨부 버튼이 한꺼번에 숨겨집니다. 단축키와 파일 끌어다 놓기, 캡처 붙여넣기는 계속 사용할 수 있습니다.

| 기능 | 단축키 |
| --- | --- |
| 선택한 글자 잘라내기 (제목·본문) | `Ctrl+X` |
| 선택한 글자 복사 (제목·본문) | `Ctrl+C` |
| 붙여넣기 (제목·본문) | `Ctrl+V` |
| 굵게 | `Ctrl+B` |
| 기울임 | `Ctrl+I` |
| 취소선 | `Ctrl+Shift+S` |
| 밑줄 | `Ctrl+U` |
| 글머리 기호 목록 | `Ctrl+Shift+5` |
| 할 일 목록 | `Ctrl+Shift+4` |
| 일반 문장으로 바꾸기 | `Ctrl+Shift+0` |
| 들여쓰기 | `Tab` |
| 내어쓰기 | `Shift+Tab` |
| 바로 저장하고 동기화 확인 | `Ctrl+S` |

**잘라내기**는 일반 문장, 글머리 기호 목록, 체크 전·후 할 일 목록에서 사용할 수 있습니다. 글자를 선택하고 **Ctrl+X**를 누르면 클립보드에 복사된 뒤 본문에서 지워집니다. **Ctrl+V**로 붙여넣을 수 있습니다. 다른 프로그램이 클립보드를 잠시 사용 중이면 자동으로 다시 시도하며, 복사에 실패하면 선택한 글자는 그대로 남습니다.

### 글머리 기호와 할 일 목록

본문에 커서를 놓거나 여러 줄을 선택한 뒤 클립 옆의 목록 버튼을 누르세요. **Enter**로 다음 항목을 만들고, 빈 항목에서 **Enter**를 누르면 일반 문장이 됩니다. 기존 항목은 같은 버튼을 다시 눌러 일반 문장으로 바꿀 수 있습니다.

본문에서 **Tab**을 누르면 문단이나 목록 항목이 바로 위 항목 아래로 들어갑니다. **Shift+Tab**은 한 단계 내어쓰기입니다. 기본 문단과 목록의 들여쓰기는 노션에도 반영됩니다. 링크나 특수 블록이 딸린 구조는 노션에서 변경하세요.

할 일을 체크하면 위젯에서 글자에 취소선이 표시되고 완료 상태가 노션에도 반영됩니다. 체크를 풀면 기존 서식으로 돌아옵니다. 체크박스 안쪽은 투명해서 메모지 배경색과 불투명도가 그대로 보입니다.

## 노션 연결

1. 노션의 주간 캘린더 데이터베이스에 날짜 속성이 하나면 그 속성을 사용합니다. 여러 개라면 **작성일**이라는 날짜 속성을 만들고 캘린더 기준 날짜로 지정하세요. 날짜는 시간이나 종료일 없이 사용하세요.
2. 노션 개발자 페이지에서 읽기·추가·수정 권한이 있는 내부 연결을 만드세요. 주간 캘린더를 전체 페이지로 열고 **••• → 더 보기 → 연결**에서 만든 연결을 추가하세요.
3. 전체 페이지로 열린 데이터베이스의 링크를 복사하세요. 위젯의 **링크 아이콘**을 눌러 이 링크와 내부 연결 토큰을 입력하고 **저장 및 연결**을 누르세요. 토큰은 Windows 사용자 계정으로 암호화해 PC에 저장합니다.
4. 위젯의 **제목**은 노션 카드 제목과, 아래 편집 칸은 페이지 본문의 텍스트 전체와 동기화됩니다. 노션에서 **Enter**로 추가한 문단, 기본 서식, 글머리 기호, 할 일의 완료 상태도 양방향으로 반영됩니다. 링크나 특수 서식이 포함된 구간은 노션에서 편집하세요.

이전 버전의 `메모` 속성은 기존 카드 본문이 비어 있을 때, 해당 날짜를 열면 본문에 복사됩니다. 이전 내용은 `메모` 속성에도 남습니다.

[노션 내부 연결 설정](https://developers.notion.com/guides/authorization/overview) · [주간 캘린더와 속성 표시](https://www.notion.com/help/calendars)

메모는 날짜당 한 장입니다. 위젯이 열려 있으면 약 5초 간격으로 노션 변경을 확인합니다. 연결이 끊겨도 입력한 내용은 PC에 저장되며, 양쪽이 바뀐 경우 위젯에서 남길 메모를 고를 수 있습니다. 종료 직전에 입력한 미전송 내용은 다음 실행 시 동기화됩니다.

## 자동 업데이트

자동 업데이트를 지원하는 버전을 처음 한 번 받아 실행하면, 이후에는 실행할 때와 실행 중 약 6시간마다 GitHub의 최신 배포를 확인합니다. 새 버전은 자동으로 다운로드되며, 위젯을 닫고 다음에 열 때 적용됩니다. 설정의 **자동 업데이트**에서 자동 확인을 켜고 끌 수 있고, **업데이트 확인**으로 직접 확인할 수도 있습니다. 현재 버전과 다운로드 상태도 설정에 표시됩니다.

업데이트 파일은 크기, SHA-256 확인값, 프로그램 이름과 버전을 검사한 뒤 교체합니다. 연결이 끊기거나 다운로드가 끝나지 않으면 기존 버전을 계속 사용할 수 있습니다. 파일을 교체할 권한이 없다면 쓰기 가능한 폴더에 위젯을 두고 실행하세요.

메모와 노션 연결 정보, 색상 등의 설정은 Windows 사용자별 `%LOCALAPPDATA%\NotionStickyMemo` 폴더에 저장됩니다. 다른 사람에게 배포할 때는 Releases의 ZIP 파일을 전달하세요. 각 사용자는 자신의 노션 연결을 설정합니다.
